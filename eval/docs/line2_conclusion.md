# line2 阶段定论 —— clip11 = 内部诚实/新颖线最优(2026-06-25)

> line2 目标(本会话):**低复制率(新颖、不靠抄,硬约束 ≈0% 底噪)+ 在此前提下尽可能真实**。
> 北极星 = 复制率 + C2ST_新颖(剔除复制后新颖子集的真实感)。续 v13-c1(L=512 富条件 + 自回归 + 攻厚尾)。

## 最优配方:`configs/line2_clip11.py`
DiT-S,SEQ_LEN=512,**CLIP_RANGE=11**,USE_CONTEXT_COND(COND_DIM=16)+ 自回归 512→2048,USE_AUX_LOSS,
2000ep(M1 实证饱和)。生成端 ⑦ `x0_clamp=20`(治罕见单窗发散)。checkpoint:`logs/line2/l2_clip11/`。

## 定版结果(full N=5120,对标 L=2048 标定 0.0%/0.495/0.326)
| 指标 | clip11 定版 | 判定 |
|---|---|---|
| **复制率** | **0.0002(0.02%)** | PASS(line2 硬约束达成) |
| **C2ST_新颖** | **0.6198** | WARN(line2 史上最优,未到 PASS 0.495) |
| 峰度(全N) | 29.7 | 厚尾充足(略超真实 19;峰度高方差,N=512 仅 10.8) |
| 诊断 | patch_spike 0.9x / d2_energy ~1.0x | 干净(无发散/接缝伪影) |

## 杠杆耗尽实证(C2ST_新颖 ~0.62 是弥散 floor)
| 实验 | 复制率 | C2ST_新颖 | 结论 |
|---|---|---|---|
| clip8 (C1 起点) | 2.2% | 0.770 | 欠厚尾 |
| **clip11** ★ | **0.02%** | **0.620** | 最优 |
| clip15 | 0.2% | 0.606 | ≈clip11 但 SigP 掉(0.193) |
| clip20 | — | (升clip触平台) | 峰度弱判别,不改善 C2ST |
| eta 0.8(零训练) | 0.0% | 0.623 | 噪声内,不改善 |
| A2 block-bootstrap | 0.0% | 0.636 | **失败**:192-块硬拼→接缝粗糙(patch_spike 40x),C2ST 反劣 |

**诊断(`eval/diagnose_c2st_features.py`)**:clip11 的 0.62 是**弥散多特征微弱分离**(无单特征 1D-AUC>0.58;峰度均值差大但 AUC 仅 0.515=弱判别 → 坐实升 clip 不改善 C2ST)。

## 结论
- **clip11 = line2 最优且封顶**:复制率 0.02%(满足硬约束)+ C2ST_新颖 0.62(每项 stylized fact 近真实、诊断干净)。
- **C2ST_新颖 0.62→PASS 0.495 的残差是数据稀缺指纹**:clip / eta / block-bootstrap 三杠杆均破不了。在保持复制率≈0 的前提下,**模型侧已无杠杆**。
- **进一步突破唯一真路 = 真实数据扩充(B1 多资产同构对)**,需外部数据,本机暂无法取。
- block-bootstrap 若要救:须**连续性保拼接**(块边界 overlap-blend)而非朴素硬拼;优先级低(clip11 已干净最优)。
